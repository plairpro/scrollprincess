# Принцесса Скролл

Уютная ночная аркада для браузера. Принцесса с красным фонарём поднимается по спиральной башне, обходя скелетов, воронов, мотыльков и другие препятствия.

**Играть:** https://plairpro.github.io/scrollprincess/

## Управление

- колесо мыши или тачпад: прокрутка вниз — шаг вверх по лестнице, обратно — шаг назад;
- на телефоне и планшете свайп вверх или вправо ведёт вперёд, вниз или влево — назад;
- стрелки на клавиатуре; `Esc` — пауза, `D` — отладка.

Скорость героини зависит от того, как быстро листаешь.

## Этажи

1. Скелеты и осыпающиеся ступени
2. + вороны на перилах
3. + руки из стены
4. + мотыльки
5. + стаи воронов
6. + скелеты-рыцари
7. Зелье скорости на лестнице: всё вдвое быстрее до 8 этажа
8. Туман: видно только то, что освещает фонарь
9. Босс: огромный скелет-рыцарь просыпается и идёт на принцессу. Отступай вниз, пока ворон, рука из стены и стая не ударят его трижды (здесь нет осыпающихся ступеней и обычных рыцарей)
10. Рыцари склоняются и уступают дорогу

На крыше принцесса зажигает от фонаря волшебный костёр, и башня становится маяком.

## Техника

Один файл `index.html`: Three.js r128 с cdnjs, вся графика строится процедурно, музыка и звуки синтезируются через Web Audio. Сборка не нужна.
